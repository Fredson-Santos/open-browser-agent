🧪 OBA CyberSec Lab

Site local só para testar a Fase 3 (intercept_rules / http_repeater) do OBA. Nenhum dado real, nenhuma rede externa.

1. Response body tampering — /api/profile

O servidor sempre devolve "admin": false. Meta: criar uma intercept_rules de Response que troque "admin":false por "admin":true no body, e ver o painel de admin aparecer aqui sem mexer no servidor.

(aguardando)
🔓 Painel de admin liberado (via interceptação do response body)

2. Status code tampering — /api/admin

Sem o cookie role=admin a resposta é 403. Meta: criar uma regra que troque 403 → 200 nesta rota (ou usar a tool cookies da Fase 2 para setar o cookie direto — teste os dois caminhos).

(aguardando)

3. Request header injection — /api/internal

Bloqueia (403) quem não parece vir de rede interna. Meta: regra de Request que injete X-Forwarded-For: 10.0.0.5 antes de a requisição saber.

(aguardando)

4. Captura para Repeater — login

Logue como guest/guest (token sem privilégio). Depois use read_network para achar esta requisição e http_repeater para reemitir /api/secret trocando o token guest pelo token admin — ou faça login como admin/admin123 em outra aba/sessão e repita o header Authorization capturado dali.

(aguardando)

5. Authorization reuse — /api/secret

Exige Authorization: Bearer <token admin>. Um token guest dá 403. Teste o http_repeater mutando o header Authorization de uma requisição capturada.

(aguardando)
